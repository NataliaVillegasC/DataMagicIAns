# SkillSense - AI-Powered Recruitment Platform

Check us out! Just go to [https://skill-sense.me](https://skill-sense.me)

## Overview

SkillSense is a comprehensive, AI-powered recruitment and talent management platform designed to revolutionize the hiring process. By leveraging advanced artificial intelligence, automated workflows, and data-driven insights, SkillSense enables organizations to make smarter, faster, and more accurate hiring decisions while providing an exceptional candidate experience.

The platform combines intelligent candidate analysis, automated CV parsing, comprehensive background verification, predictive performance modeling, and team composition optimization into a single, intuitive interface. From initial candidate sourcing to final hiring decisions, SkillSense streamlines every step of the recruitment lifecycle.

### Database Schema

**Core Tables**:
- `profiles`: User accounts and company affiliations
- `candidates`: Candidate master records
- `job_openings`: Job posting definitions
- `applications`: Candidate-job associations with status
- `interviews`: Scheduled interview records
- `survey_responses`: Candidate assessment results
- `ai_insights`: Cached AI analysis results
- `background_checks`: Background verification reports
- `skills`: Normalized skill taxonomy
- `candidate_skills`: Skill-candidate mappings with proficiency

**Security**: Row Level Security (RLS) policies enforce data access rules based on user authentication and company membership.

## Setup Instructions

### Prerequisites

- **Node.js**: Version 18.0 or higher
- **npm**: Version 9.0 or higher
- **Git**: For version control

### Installation

1. **Clone the repository**
```bash
git clone <repository-url>
cd skillsense
```

2. **Install dependencies**
```bash
npm install
```

3. **Environment Configuration**

The project uses Lovable Cloud, which automatically provisions and configures the backend infrastructure. Environment variables are automatically generated and include:

- `VITE_SUPABASE_URL`: Backend API endpoint
- `VITE_SUPABASE_PUBLISHABLE_KEY`: Public API key
- `VITE_SUPABASE_PROJECT_ID`: Project identifier

These are managed automatically and do not require manual configuration.

4. **Start development server**
```bash
npm run dev
```

The application will be available at `http://localhost:5173`

### Building for Production

```bash
npm run build
```

This generates optimized production assets in the `dist/` directory.

### Deployment

This project was built with [Lovable](https://lovable.dev), which provides integrated deployment:

1. Navigate to the Lovable project dashboard
2. Click "Publish" to deploy the application
3. Frontend changes require clicking "Update" to go live
4. Backend changes (edge functions, database migrations) deploy automatically

For custom domain setup, configure DNS settings in Project Settings → Domains.

## Key Workflows

### Candidate Evaluation Workflow

1. **Upload CV** → Automatic parsing extracts structured data
2. **AI Analysis** → Comprehensive evaluation across 9 dimensions
3. **Survey Invitation** → Candidate completes assessment
4. **Survey Analysis** → AI generates personality and competency report
5. **Background Check** → Verification of credentials and history
6. **Interview Scheduling** → Automated communication and calendar management
7. **Team Fit Analysis** → Evaluate candidate in team context
8. **Hiring Decision** → Data-driven recommendation with confidence scoring

### Job Opening Workflow

1. **Create Job Opening** → Define role requirements and skills
2. **Receive Applications** → Candidates apply or are sourced
3. **Automatic Matching** → AI scores candidate-job fit
4. **Pipeline Management** → Track candidates through stages
5. **Interview Scheduling** → Coordinate interview logistics
6. **Team Building** → Assemble optimal team composition
7. **Offer Extension** → Data-driven compensation recommendations
8. **Analytics Review** → Track hiring metrics and optimize process
